# bond-yahoo-valuation-and-legacy-removal

Objective: make Argentine ONs (corporate bonds) correctly valued in the live backend/frontend path by normalizing Yahoo quote percentages to per-nominal-unit prices, and retire the dead Streamlit + `finance.db` code.
Branch: `dev`. Delivery strategy: `ask-on-risk` (no PR reordering; single focused session, work-unit commits at most one per task).
Test runner: `python -m pytest backend/tests -q`. Frontend untouched.

## Specs

- **S1** — The yfinance adapter divides `currentPrice` / `regularMarketPrice` / `previousClose` by `100` **only when the instrument's `quoteType` is `BOND`** (ONs quote as a percentage of par). Non-bond quote types (e.g. `EQUITY`) keep the raw price.
- **S2** — Historical series for `BOND` instruments are divided by 100 as well, so current price and chart series are in the same units.
- **S3** — The composite provider's yfinance fallback path (`CompositeMarketDataProvider.get_quote` and `get_historical_series`) applies the same `BOND` ÷100 rule. PPI behavior is unchanged (it already divides by 100).
- **S4** — Legacy code retired: `main.py`, `src/`, `requirements.txt`, `tests/`, `debug_wishlist.py`, `test.ipynb` removed from the tree. `finance.db` stays on disk (user data, untracked, migration source) and is NOT deleted.
- **S5** — `README.md` loses the Streamlit install/run instructions and states the web app uses backend + frontend; `CHANGELOG.md` and `CHANGELOG_es.md` record the removal and the bond fix under Unreleased.
- **S6** — `python -m pytest backend/tests -q` passes with the new adapter tests; no CI workflow changes are required (CI already installs `backend[test]`).
- **S7** — The user can explicitly flag any ticker as "quoted per 100 nominal units" from the settings workspace; flagged tickers are divided by 100 at the yfinance provider/composite fallback even when Yahoo reports `quoteType: "EQUITY"` (which it does for BYMA ONs like `YFCOO.BA`). The flag lives in the existing `app_settings` store (key `percent_of_par_tickers`), needs no schema migration, and applies to quotes and historical series. PPI-served instruments are NOT affected (PPI already reports per-100). Exposed as `GET/PUT /api/v1/percent-of-par-tickers` and a settings UI section.
